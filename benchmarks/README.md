# TCRIA Benchmarks

This directory contains reproducible, high-demand governance cases.

A benchmark is intentionally split into two contracts:

1. **TCRIA deterministic contract**: source integrity, extraction, signals, classification, gates, traceability, and promotion boundaries.
2. **AI-assisted comprehension rubric**: a human-reviewed evaluation of whether an assistant can explain the governed record without converting allegations into established facts.

The AI rubric never changes the official TCRIA outcome. It evaluates comprehension of an already governed documentary surface.
